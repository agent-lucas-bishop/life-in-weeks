# 📊 Life in Weeks

A life visualization micro-tool. See your entire life laid out in weeks.

## 🔗 Try It

**[life-in-weeks-orcin-xi.vercel.app](https://life-in-weeks-orcin-xi.vercel.app)**

## About

Inspired by Tim Urban's "Your Life in Weeks" concept. Enter your birthday and see a grid of every week in a typical lifespan — past weeks filled in, future weeks waiting.

## Tech Stack

- React 19 + TypeScript
- Vite
- CSS Modules
- Deployed on Vercel
